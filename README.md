# Classificador de Nível de Herói 🎮

Este é um projeto desenvolvido para o desafio de lógica de programação do bootcamp da **DIO (Digital Innovation One)**. O objetivo é classificar o nível de um herói com base na sua quantidade de Experiência (XP).

## 🚀 Tecnologias Utilizadas
- **Python 3**
- Estruturas de repetição (`while`)
- Funções e escopos estruturados (`def` / `return`)
- Estruturas condicionais (`if`, `elif`, `else`)

## 🛠️ Como Funciona
O programa roda em um laço contínuo perguntando o nome do personagem e o seu XP atual. Ele processa o rank através de uma função isolada e exibe o resultado final, permitindo analisar múltiplos heróis em sequência.
